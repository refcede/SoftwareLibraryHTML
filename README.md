# 🚀 Cibay Software Library

Ini adalah projek website saya dengan bahasa pemrograman HTML, Sebuah portal arsip *software* dan pusat materi perkuliahan yang didedikasikan untuk membantu mahasiswa mendapatkan "alat tempur" pemrograman dengan mudah, cepat, dan terpusat. Dikembangkan secara khusus untuk mendukung kebutuhan akademik untuk rekan rekan mahasiswa saya.

🌐 **Kunjungi Website:** [Cibay Software](https://refcede.github.io/SoftwareLibraryHTML/)

## 🎯 Tujuan
Repositori dan *website* ini dibuat untuk mengatasi kesulitan mahasiswa dalam mencari instalasi perangkat lunak (IDE, *environment*, *tools* analitik) dan materi pembelajaran yang aman. Semua tautan unduhan diarahkan secara langsung (via MediaFire/Google Drive) tanpa melewati *link shortener* yang mengganggu.

## ✨ Fitur & Kategori Utama

### ☕ 1. Java Environment
Peralatan wajib untuk memulai pemrograman dan basis data:
- **Java JDK:** Tersedia versi 24 (Terbaru), 17 (LTS), dan 8 (Legacy).
- **Web Server & Database:** XAMPP dan Portable MySQL.
- **Dependencies:** MySQL Connector `.jar` dan FlatLaf `.jar` untuk UI Java Swing.

### 🛠️ 2. Development Tools
Koleksi IDE dan perangkat lunak akademis:
- **Code Editors / IDE:** Apache NetBeans (v27 & v8.2), Visual Studio Code, Notepad++, Dev C++.
- **Spesifik Mata Kuliah:** Cisco Packet Tracer (Jaringan), SPSS (Statistik), Python 25.

### 📚 3. Arsip Materi Kuliah
Akses langsung ke E-Book dan Modul (PPT) untuk mata kuliah:
- Pemrograman Berorientasi Objek (PBO) II
- Perancangan Basis Data II
- Algoritma & Struktur Data
- Jaringan Komputer
- Sistem Operasi
- Java Web Programming
- Statistik II

### 🎮 4. Refreshment
Koleksi permainan ringan untuk *refreshing* di sela-sela waktu *ngoding* (Plants vs. Zombies, GTA Extreme Indonesia).

## 🛠️ Tech Stack
Teknologi yang digunakan dalam pengembangan dan *hosting* portal ini:
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Deployment & Hosting:** [GitHub Pages](https://pages.github.com/)
- **Storage/File Hosting:** Google Drive & MediaFire (untuk penyimpanan *file* eksternal)

## 💡 Informasi Tambahan & Bantuan

- **Password Arsip:** Sebagian besar file RAR/ZIP menggunakan *password* `123` atau `www.kuyhaa.me` (perhatikan nama file saat mengunduh).
- **Keamanan:** File berupa *crack/patch* mungkin terdeteksi sebagai virus oleh Windows Defender (False Alarm). Disarankan menonaktifkan antivirus sementara saat proses instalasi.
- **Request Software:** Tidak menemukan *software* yang dibutuhkan atau menemukan *link* mati? Silakan gunakan fitur **Request** di bagian bawah *website* untuk menghubungi admin via WhatsApp atau Google Form.
